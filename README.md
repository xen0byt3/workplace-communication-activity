## Operational Terms and Definitions

The following terms are used in workplace communication and Security Operations Center (SOC) activities:

- **HOTFIX** – An urgent software update used to resolve a critical issue.
- **PATCH** – A small software update designed to fix bugs or security vulnerabilities.
- **BACKDOOR** – A hidden method of bypassing normal authentication or security controls.
- **LEGACY** – An older system or software module that is still in use.
- **PING** – To contact someone or check communication with a system.
- **BUG** – An error or defect in software.
- **SANDBOX** – An isolated environment used for testing without affecting production systems.
- **PROD** – Short for production, referring to the live environment used by actual users.
