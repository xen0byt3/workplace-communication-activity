### Operational Terms Glossary

 **DOWN**: A server, service, or system is offline, unreachable, or not functioning.
 **PING**: To contact, check status with, or request assistance from a person or team.
 **BUG**: A flaw, error, or defect that causes software to behave incorrectly or produce unexpected results.
 **SANDBOX**: An isolated, safe environment used for testing changes without affecting live systems or real users.
 **PROD (Production)**: The live, official environment where real users interact with the system daily.
 **STAGING**: A pre‑production test environment that matches production exactly — used to verify updates before release.
 **HOTFIX**: An urgent, targeted fix applied directly to live code to resolve a critical issue immediately.
 **PATCH**: A software update released to fix bugs, close security gaps, or improve performance.
 **BACKDOOR**: Hidden or undocumented access that bypasses normal security — considered a serious vulnerability.
 **LEGACY**: Outdated technology, code, or systems still in use but no longer updated or fully supported.
